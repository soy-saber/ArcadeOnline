# 僵尸危机3：受击、死亡、尸体与复活

2026-10-25，本批本地验收完成，待推送和发布。以仓库原始 `games/50737/game.swf` 的静态AS2为依据，源SWF未改写。类哈希、动画帧数、参数与未完成范围见 [来源记录](source-review.json)。本批不代表全游戏还原目标完成。

原先命中后直接扣血、立即记杀并替换为定时尸体的逻辑，改为角色受击队列与共享状态流程。队列等到目标的角色回调处理，按最近加入的影响先处理；先保存受击前朝向，按实际来源XYZ及目标质量求击退，随后清除竖直分量。人物/僵尸/恶魔质量分别为2/1/5。子弹、火球、僵尸近战和爆炸保留各自不同的最大/最小速度公式，不能合并成统一击退强度。原受击计数由初始速度反复乘0.65直到小于0.01格求得；每回调先处理圆形/地图碰撞，使用实际剩余位移再乘0.65，计数减到小于0才结束。即使撞墙停住，原受击时间仍继续。

受击时释放原目的格，身体仍可发生物理碰撞；原两个受击动作随机选一个并停留在第0帧。期间不执行人物移动、换枪、开火、回血和武器冷却更新；物理按键仍接收，合法的开火/选枪边缘保留到控制恢复，过期/断线则清理。未致命时恢复受击前朝向，站立休息3次回调，再回到基本控制/AI；人物控制初始化立即运行一次控制，僵尸则下一回调继续Goto。恶魔自己的发射计数仍在受击/尸体回调后递减，保留其Process_Normal外层顺序。

致命伤先进入受击/击退：第一回调设置DEAD并清除可受伤标记，避免继续被伤害和捡血；身体圆形仍保留。击退结束进入Dying时才记一次击杀/死亡、播放原死亡声并取消碰撞。倒地使用原5帧、每回调0.34帧，结束后播放HitFloor并归地面层。僵尸/恶魔尸体从50计数，51次Dead回调后标记删除，再下一回调真正移出Mapwho模型；最后25次按减计数前的值渐隐。尸体仍是登记对象，会影响原格内放置计数及波次清场，不能在掉血为0时立即删除。

人物尸体从100计数，101次Dead回调后进入初始25计数的Respawn；第26次尝试复活。复活候选限定原地图玩家出生标记，选择最近存活队友附近、距离至少2格、原19/13格范围内且没有Creature/Object/Player标记的候选；没有候选时保持等待，之后每回调重试，不在全地图找一个任意空格。四人适配选择最新的存活队友。复活前先重建空手动作并给保护，再按原顺序立即执行一次旧武器控制，随后Renew FIRE、恢复200生命、清空有限弹药并选手枪；没有把这次原回调吞掉。保护125计数在本回调末减一次，原奇数计数完全隐去的闪烁也保留。全队死亡在原Dead渐隐通知阶段才结束，不在致命命中当帧直接结算。

人物常规移动补上原注册角色/物件的圆形碰撞、最多三次PlayerCollide与原地图滑动优先级；受击走一次CreatureCollide。完全重合时保留现有确定性有限值退避，避免复现SWF的NaN错误。玩家回调仍写Player标记，包括倒地/尸体/等待复活，伤害与物理标记分开。受击、死亡、尸体和等待复活都由服务器快照保存；预测在禁控状态停止。24张原受击/倒地/尸体图提前加载，避免首次死亡时空白首帧。血迹移到地面，补原0.6纵向压扁与±8像素随机偏移；完整图案变体/方向、原地面mask及永久地面缓存仍待继续。

原CSound中的僵尸受击/死亡四个别名实际指向Ambience.1～4，并非统一的Zombie.Hit；人物没有另一个受击声。恢复这些别名及0.4音量，人物Scream.1为0.7、HitFloor为1，音量滑块更新仍使用对应增益。原有音效去重及静音行为保留。
