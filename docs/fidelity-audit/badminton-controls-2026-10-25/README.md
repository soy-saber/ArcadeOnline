原始依据为 `games/46923/game.swf`，`frame_38` 的 `setupHero1/setupHero2/reset/p1Scored/p2Scored/setupBirdie`，球拍 `283/205`、发球拍 `285/211` 的逐帧AS2及P-code，舞台XML的原透明墙与netLimit矩阵。来源哈希及动作脚本见 [source-review.json](source-review.json)。没有把去混淆器错误折叠的getTimer常量移植为游戏计时。

网页原来按键边沿跳跃、按住每500ms补发一次挥拍计数，把普通拍与发球拍压成一个倒计时，动画结束后又画回帧1。本批用两个独立轨道与原共享 `Swing/RacketReady` 标记，普通拍从帧2启动，帧9关闭窗口，帧15就绪并停在末帧；接触只取消当前击球机会，动作继续。发球由帧1的play推进，帧4生成球并取消双方活动挥拍标记，帧13解除serve，随后回到帧1就绪。非发球方可在发球前挥拍。保留双人上手动作，单人下手素材不混入双人控制。

服务器接收实际按住状态，按住挥拍在就绪后继续出手，按住跳跃在落地后再次起跳。计数只补偿两次网络采样之间的短按；松键不取消已开始的动作。W/↑、S/↓混用保持一个逻辑按住状态。失焦、切换座位/输入状态会发送取消计数，过期/重连输入消费待执行边沿并清除按住，避免恢复时多挥或多跳。挥拍音效由近期服务器确认的出手事件触发，取消按键和不就绪时按键不会自行播放出手音。

人物先加重力、移动Y、落地夹紧Y并清jump，保留原地面竖直速度累计；起跳再设原12像素冲量。移动按原先检测注册点、再走5.9像素，右键先于左键；墙按原旋转21像素方框，netLimit按原宽矩形及发球65/60像素偏移。移除人工中线夹紧，允许原单步越入墙边与高于netLimit时跨越。预测使用相同水平判定，只预览本地移动/跳跃，球、球拍、计分与回合定时由服务器确认。

普通得分在得分回调之后完整45个30Hz回调（1500ms）复位；旧倒计时在得分同回调先减1。本批以绝对resetAt/finishAt保存。P1第7分按原等待1500ms后结束，P2第7分按原立即结束。换发只复位球与发球位置，不重建或清空人物/跳跃/两条球拍轨道。完整/增量、观战和恢复保留新状态与校验。
