# 疯狂小人战斗：原动作、角色战斗与道具流程

按用户要求，原菜单/HUD/过场外观可简化，选图、换人物等对应功能仍须完整。本批接续六人物选择，恢复比赛中的原动作、专属特技与战斗流程。全部八款的整体目标仍为 active，剩余项见[总清单](../../../ALL_GAMES_REPAIR_PLAN.md)。最新实际公网版本见[部署记录](../../../DEPLOYMENT_STATUS.md)。

## 本批行为

- 六人物按原23个根标签选择动作，使用自然子时间轴播放帧及原红/蓝/绿/橙颜色脚本，保留真实像素大小、注册点与原边界；替换原先四张缩放静态图和统一攻击弧线。空的 hanging 标签保留空图，不造人物动作。颜色当前按在线席位分配，完整自选颜色/队伍尚待实现。
- 原逻辑周期25ms（40Hz），动画按原30FPS推进并执行 stop/goto；例如 run 的跳回第4帧不再以简单取模代替。四场景改用 SpawnP1..4 的人物点，稀疏席位按参赛顺序取点；SpawnH1..4 仅作随机道具生成区域。移除人为五分钟股票赛结算。
- J/空格攻击，K/X专属特技，Shift防御；快速上+攻击/特技、上键释放/长按跳跃、二段跳、蹲下与穿薄平台、闪避、抓取背投、受击停顿、失控、倒地恢复、损伤/连击、护盾消耗/恢复及重生保护按原类组织。保留 WASD/方向键兼容及触屏特技/防御按钮。
- 圆球电球/电击、咖啡投射物、茄子铅笔、草莓波束、垃圾桶投射物/20碎片上特技、桃子枪弹/火箭分别处理。原发射位置、比例、阶段、伤害和击飞不再共用一套距离攻击。
- 原默认物品表只含地雷和手雷。按原概率/频率在 SpawnH 区域生成，静置物品不自行下落，攻击先拾取，再攻击投掷；手雷碰撞爆炸，地雷碰撞附着后延时激活；爆炸半径、一次影响、盾与击飞使用原公式。原投射物/道具/护盾/出生/爆炸等图像来自原符号时间轴。
- 恢复26条原音频来源与原 Snd.AddSound 别名列表，接入战斗音效、四场景音乐及屋顶直升机/B52引擎循环，沿用音效开关和音量。MP3保留压缩载荷，PCM加WAV头，SWF ADPCM由FFDec解码成WAV。

## 依据与证据范围

原作 `games/6232/game.swf` SHA256：`c23074f428e1a3bdb4a6c44779627d87b7b3ff0ad00518ceaab94dd3943b8f77`。依据包括 frame_42/frame_51、Fighter、World、PlayerControl/KeyCombi、六人物类、Projectile及各投射物、Item/Mine/Grenade/ItemGen/Explosion、Snd 与嵌套帧脚本。

`prepare-brawler-native-reference.py` 保留原类初始化器、符号、嵌套时间轴、图形和媒体的原始SWF字节，仅替换根入口/显示流为隔离探针。保留标签摘要为 `173b8772dc9453b3605711ea41da359e16aa2350ef300729831a7444b622042f`。本地Chrome/Ruffle运行原类的 Attack/ParseAttacks/ParseSAttacks/Damage/Throw 与坐标设置，收集[3,275组原运行记录](../../../tests/fixtures/brawler-native-rules.json)，由5组测试逐条比对。上特技20碎片分支以AVM1实际运行结果为准，避免直接翻译反编译条件时丢失其 undefined 比较语义。随机碎片类型作为观察到的外部输入回放，不宣称共享原随机数流。

角色图来自588组自然播放任务：8,068个可见帧观察与56个原goto跳转别名，按测得原点裁切/打包为24张色彩图集。原嵌套色彩/播放脚本实际执行；图集保留边界和手/投射物标记数据。17类对象共42段原图时间轴捕获，保留每帧根位移/角度/边界。对象捕获导出降为10FPS以避免重图形渲染追帧，先静态审计所有相关图形帧脚本不存在 getTimer/setInterval/setTimeout，再按原30FPS回放。每个捕获步都要求恰好一个原动画帧；失败的30FPS对象捕获未作成品依据。源哈希、探针哈希、原渲染版本、图集哈希和采集方法分别保存在公开素材的 provenance、objects-provenance 与 audio/provenance 中。

这些是**隔离原函数/原素材时间轴**证据，不等于运行整个原Flash游戏，也不宣称Adobe Flash逐像素或全部世界调度等价。当前平台碰撞按 World 的AABB/边缘点探测分支移植；辅助实例精确枚举/原生边界与完整世界连续轨迹仍须补原运行对照。

## 联机适配与已知差距

快速上键释放和上击组合以计数事件传输，避免25ms输入采样漏掉短按；取消、失焦及过期输入会消耗事件。投射物首次移动推迟到下一逻辑回调，耗尽后保留两个逻辑tick（50ms）画面供20Hz快照显示，期间不再命中。抓投被打断或出界时释放另一真人的控制，避免在线对手永久失控。这些是明确的联机适配，不能标为原完整事件循环等价。

仍待继续：原自选颜色/队伍、全部模式/时间或股票数/物品频率等规则设置、AI/单人/教程等对应功能；完整场景动画、Boom/Killer辅助区、原摄像机；持物时身体嵌套动作/原物品指示器、全部命中特效/死亡表现及精确滤镜；原完整集合/定时器顺序、地图几何和所有机制组合的原运行轨迹。持物当前为原物品图的附加显示，不能称完整持物动作还原。30FPS动画状态由服务器推进，客户端当前跟随20Hz权威快照选帧，尚未补独立平滑播放所有原动画帧。

本批没有完成全八款修复，也没有重测公网链路容量、异地延迟或实际TURN中继吞吐。
