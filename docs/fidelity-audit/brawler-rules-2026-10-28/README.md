# 疯狂小人战斗：对局规则与物品初始化

原菜单外观继续简化，选人、选图和对应功能保留。这一批补生命制、计时制、道具频率、暂停/继续/返回和原结算，并修复上一批明确记录的物品状态图及碎片分型初始化问题。所有对局判定由服务器执行；全八款修复目标仍在进行，见[总清单](../../../ALL_GAMES_REPAIR_PLAN.md)。

## 行为与原作依据

- 原默认生命数为5，可自定义正整数；计时制默认300秒，0为不限时，出界后无限复活。切换生命制/计时制时恢复对应默认数值。设置仅房间控制者可改，对局中锁定；改变规则须重新准备。选人、四图、换座、重连和完整/增量恢复继续保留。
- 道具频率包含关、极低、低、中、高、极高六档，对应原值0至5。0完全停止生成；其他档按原 `10000/frequency` 间隔、`random(2+50/frequency)` 概率和整数生成区域取点处理。原AVM1计时器参数会转为整数，不能把3333.333毫秒直接保留为原调度周期。
- P或按钮暂停、继续；全屏中可继续或返回准备。暂停冻结时间、物理、道具和动画，并消耗旧输入，继续后不会因暂停前按住方向而自行走动；被击飞的惯性仍保留。返回准备保留规则、取消双方准备。结算后沿用平台3秒自动再开，这是联机平台的流程适配。
- 计时分数为原KOs减Deaths，生命制按最终淘汰顺序排名。原作会将自身归因死亡同时加KOs和Deaths；这里以独立 `nativeKos` 保留原结算，房间战绩仍只计算击杀对手。无归因死亡按原规则计SD。并列时遵循原AVM1排序的实际顺序，不额外发明平局规则。
- Mine和Grenade裸符号进入第1帧后会跳至airbone，原来直接请求spawn/active的采集被入口脚本覆盖。本次先执行入口，再调用原init/Throw/DoCommon/HitWall，重采spawn、飞行和激活状态；每个固定状态的每一捕获帧都核对真实根帧。独立 `artAge` 在投掷/激活时重置，生命周期年龄继续推进。
- Garbage先执行构造时随机，再按原init处理type：0保留构造结果；1在非第1帧时重新进入随机入口；2至6使用指定帧。不能把type0强制改成type1。图集为每个分型条件采集，运行时另执行随机初始化。

来源包括仓库原 `games/6232/game.swf`、Fighter.Die、frame101、ItemGen、Mine/Grenade/Garbage、原规则按钮和数字设置脚本。原SWF SHA256为 `c23074f428e1a3bdb4a6c44779627d87b7b3ff0ad00518ceaab94dd3943b8f77`，保留标签摘要为 `173b8772dc9453b3605711ea41da359e16aa2350ef300729831a7444b622042f`。

排序移植对照当前原运行环境Ruffle nightly-2026-08-06的[AVM1 array.rs中qsort](https://github.com/ruffle-rs/ruffle/blob/nightly-2026-08-06/core/src/avm1/globals/array.rs)；它以左端为pivot，相等元素可能换位。计时器整数转换见同版本[globals.rs中create_timer](https://github.com/ruffle-rs/ruffle/blob/nightly-2026-08-06/core/src/avm1/globals.rs)。这描述当前隔离原运行环境的行为，不扩大为全部Adobe Flash版本的证明。

## 证据范围

[原物品初始化夹具](../../../tests/fixtures/brawler-initialized-objects.json)记录Mine三种、Grenade两种、Garbage六种状态，以及84次类型初始化和160次构造依赖观察。[原结算夹具](../../../tests/fixtures/brawler-match-native.json)包含9次原Fighter.Die、10组结算和最多四人时全部92种分数弱序关系。Fighter.Die使用保留的原SWF方法字节；frame101则在隔离函数中重新编译未改动的恢复源码，两种证据明确区分。

17类对象的42段时间轴各采90帧，按测得注册点和边界重新导入图集。固定状态先完成原初始化；为采图清除物品原定时器，指示器与世界碰撞依赖用外部替身隔离，未替换原物品方法。Garbage第1帧的图仅对真实随机结果为1的分支条件采集。自然播放片段保留原播放流程。导出10FPS、每步一原帧，相关图形子脚本无实时时钟调用，再按原30FPS播放；运行时物理仍为40Hz。原24张人物图集、8,068帧身体动作未在本次重新导出。

这些属于隔离原函数、原素材和服务端移植核对，不是完整原Flash世界等价证明。浏览器过程使用真实server.js、三个Chrome身份、普通UI/键盘和只读状态观察，不注入生命、位置、库存或结算。自然物品专项只将频率通过正式UI调为5，仍等待真实随机生成、移动拾取和再次攻击投掷。

本地验证及实际过程见本目录证据；公网版本、包哈希与结果在发布完成后单列记录。
