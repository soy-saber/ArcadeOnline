# 原版射线、火箭与内层素材时间轴

以 `4ae43e0` 为基线，继续按原 `games/50737/game.swf` 的 AS2 核对。原 SWF 未修改；来源哈希、类文件哈希与规则见 [source-review.json](source-review.json)。整体目标仍按 [完整清单](../../../BOXHEAD_RESTORATION_PLAN.md) 推进。

本批替换旧的 4 像素逐点射线和火箭 5 像素步进。`CMap_Collide.Collide_Line` 按一格步长访问四舍五入后扩展的格范围，同次查询去重，逐批寻找命中；静态墙按边界求交。`CMap_Cell` 的物体测试使用 `CLine.QDistance_PointToLine_SQR`，这是未截断的直线距离，查询本身由访问格范围约束。查询半径 0.04 格只参与格范围，不能额外加到人物半径。人物命中点按来源到中心的方向后退目标半径，保留原逻辑。

子弹在构造时保存完整目标端点及原随机飘移，在下一回调 Init 时才命中；Init 随即执行第一次 Normal。两次 Normal 各将飘移乘 0.75，起点移动一个飘移、终点移动半个飘移，分别保存高度；第二次回调标记 Delete，最后一帧保留至下次移除。UZI 移除旧的额外随机散射。霰弹枪按原中心、负/正第一对、负/正第二对的顺序构造；升级后外侧第二对先执行 Delay，额外等待一次回调。轨道炮先只对地图墙截线，再对沿线全部对象施加伤害，因此可穿透假墙与敌群。普通子弹在任何碰撞时均播放原三个随机弹着声之一，并有三分之一概率产生原弹着特效；轨道炮没有这两个事件。

火箭恢复 0.5 格初速、每回调乘 1.1，先判断整段射线再 Move。没有固定 100 帧引信；原预构造爆炸共享火箭位置，碰撞后保留移动前位置，在后续回调初始化爆炸。尾烟由原二选一随机数决定，在原高度、原尺寸绘制，向后以 0.5 格初速、每回调乘 1.2 漂移，播放六帧后延后移除。

本批还发现旧素材导出漏掉 `_Contents`：`Shot.Rocket` 外层一帧、内层三帧；`Effect.BulletHit` 外层一帧、内层十三帧。新增 [静态导入脚本](../../../scripts/import-boxhead-shot-art.py)，只扩展分析副本的外层时间轴，保留原滤镜及 SVG 定位，源 SWF 不变。完整来源和各帧像素哈希在 [素材元数据](../../../src/expanded/boxhead-shot-art.json)。火箭按每回调一帧循环，保持原位图方向；弹着特效每回调一帧，末帧保留到下一次移除。

权威状态保存射线 Init/Delay/Normal/Delete、起终点 XYZ、飘移、父对象与出生回调；火箭与尾烟的位移、速度和出生时间也可恢复。原放置格计数现在只计入已经 Init 的射线，并保留等待 Dispose 的末帧射线。服务器验证拒绝缺失/非有限字段、错误阶段寿命及旧的火箭 100 帧状态。

完整集合的全局回调与 Mapwho 插入历史仍待移植：当前同格对象顺序按较新分配 ID 优先，尚未重现对象离格再进入后的历史；各类对象仍有独立处理阶段。不能据此宣称完整 Flash 逐帧等价。手雷的高度/法线、原 AI 视线调用、波次/升级/补给/难度、模式/选人与 HUD、永久地面缓存等仍在原目标范围内。

367项默认单测、5项部署检查、类型检查及构建来源检查通过。新增13项射线专项测试覆盖静态边界、斜线/短段、边缘命中、同格顺序、无限直线距离、友伤延迟、UZI随机数、霰弹延迟、轨道炮穿假墙/静态阻挡、原声音/弹着、火箭爆点/无引信/尾烟、四个射线阶段/火箭的完整与增量恢复、异常状态及16张原内层帧的像素校验。旧墙体/连锁/友伤测试按原下一回调命中修正，原生命、伤害与命中次数未放宽。

真实双Chrome自然108击杀、最高71连击后解锁轨道炮，实际五发升级霰弹、放置1000HP假墙、轨道炮同时将墙打至900HP并将后方队友打至100HP、火箭消耗/飞行/移动前爆点与尾烟通过。Init/Delay/Normal/火箭阶段均实际请求并接收完整快照；全部三帧火箭和十三帧弹着均被Canvas实际绘制，射线原宽度/颜色/透明度、尾烟原128像素尺寸通过。[实际记录](rays-results.json) 与截图保留在本目录。
