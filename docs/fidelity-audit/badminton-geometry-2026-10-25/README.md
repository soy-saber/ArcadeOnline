# 羽毛球原球拍矩阵、发球点与击中后动作

本批以 `bb56f97` 为基线推进“完成羽毛球和僵尸危机3的复原工作”。新增 [羽毛球完整清单](../../../BADMINTON_RESTORATION_PLAN.md)，僵尸危机3沿用并明确关联 [原清单](../../../BOXHEAD_RESTORATION_PLAN.md)。整体目标尚未完成，不能把本批双人对战改动当作全部模式已恢复。

原始依据是 `games/46923/game.swf`、XML `DefineSprite_306/268` 的角色枪拍变换、`283/205` 上手与下手时间轴、`186.racket.hitbox` 的透明21像素方框 `117/118/119`，以及 `285/211` 发球时间轴和 `190.mc.Point` 的 `localToGlobal`。原AS2 `setupBirdie` 对拍面使用 `hitbox.hitTest(x,y,false)`，按变换后舞台坐标的包围矩形检测；旧实现用估计拍头坐标和半径30圆形检测，在矩形角部会漏球，也会接受框外的球。

新增 [静态导入脚本](../../../scripts/import-badminton-geometry.py) 从原XML逐帧重建显示列表，保留移动、替换、移除、实例名和父子矩阵，生成44帧球拍的矩阵/矩形/拍面角、26帧发球标记及原角色gun/gunServe矩阵。源SWF不变；导入时可用JPEXS重导70张既有PNG和SVG定位，确认图像尺寸/滤镜与文件哈希。原PNG本身未改变，本批替换的是人工定位，绘制改用原角色矩阵与SVG注册偏移。元数据、来源哈希和图像逐文件哈希见 [geometry.json](../../../src/badminton/geometry.json)。

发球、等待与换发状态使用原标记点；释放帧仍为第4帧，并在同次球处理立即应用原阻力/重力。P1标记相对角色为 `(23.8,-29.5)`，P2为 `(-21.65,-28.5)`，替代统一 `±25,-75`。实际接触采用原逐帧矩形、镜像与局部拍面角。击中后保存 `swingHit`，消耗本次击球机会但继续播放剩余动作，直到原动作完成才可再次挥拍；该标记进入完整/增量快照及校验。死球阶段仍可挥拍改变球的运动，已结算比分不会再次增加。保留原P1先、P2后的接触检测顺序。

另核对出：原双人 `setupHero1` 只启动上手帧2；低球下手分支在单人 `setupHero`。因此当前双人模式取消错误的P1低球自动下手，原14帧下手素材/碰撞数据保留供后续单人模式使用。原整体控制仍有按住输入、人物完整动作、发球末帧/回调等差异，需要继续复原。
