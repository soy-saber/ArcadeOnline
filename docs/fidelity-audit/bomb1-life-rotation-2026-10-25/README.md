# 泡泡炸弹人1：联机额外生命与每五局随机换图

按用户要求修复。旧拾取处理已经加生命，但普通无保护受击仍强制淘汰联机真人；额外生命沿用单机闯关库存语义，而联机没有相应过关消耗流程。联机现在受击扣一条生命，尚有库存时继续并获得60 tick保护，耗尽才出局。护盾先消耗，存活受击不增加死亡或对手击杀。单机闯关真人的原出局规则保留。

仅泡泡炸弹人1：每张地图累计实际完成5局，第5局结算画面保持旧图，第6局从另外4张原作地图中等概率随机选一张，不连续选到当前地图。等待、准备、阵容重建和中止不累计。手动改为另一张图重新计数，难度单独调整不清零；换图保留准备状态和累计战绩。

本地8项专项及相关计分回归通过，随机测试对每个当前地图验证另外4个候选均可被选中。真实双Chrome上下文实际拾取生命1→2，真实炸弹第一次消耗后存活、保护自然结束后最后一条耗尽才淘汰，完整恢复保留生命；实际完成5局，前5局森林，第6局随机抽到糖果屋，双方地图、选择器、准备与计数一致。见 [结果](results.json)、[生命2](life-pickup-two.png)、[第一次爆炸后存活](life-survived-first-blast.png)、[第5局](fifth-round-map-next.png)、[第6局随机地图](sixth-round-random-map.png)。夹具只安排道具/安全站位/障碍并清理场景，不修改属性、保护、引信、比赛阶段或局数。
