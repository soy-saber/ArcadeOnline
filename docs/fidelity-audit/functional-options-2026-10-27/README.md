# 原功能补齐：选人、模式、选项与暂停

2026-10-27用户明确：原菜单等画面可以不复刻，选图、换人物等功能仍须实现。本批沿用现有房间界面，不将原菜单、HUD字体布局或过场影片作为剩余视觉阻塞项；比赛内原人物、地图、武器、音效和玩法继续还原。

## 功能

- 僵尸危机3：18图、SWAT/BOND/GIJOE/BAMBO本人选人，允许重复角色；稀疏席位、换图/模式、刷新/换座后保留选择。原四套角色素材继续绘制。
- 单人生存仅P1准备即可开始；合作2–4人；死亡竞赛2–4人。死亡上限5/10/20/50，达到后淘汰，最后存活者获胜，同时淘汰为平局。多人淘汰是原双人死亡竞赛的四人适配。
- 四档难度原起始波次1/10/20/35、倍率1/10/30/50；速度0.5/1/2对应12.5/25/50回调每秒。恶魔、移动实体碰撞、玩家枪弹/爆炸伤害可切换；地图墙仍阻挡，关闭弹爆伤害仍受近战/火球伤害，死亡竞赛强制开启弹爆伤害。退出死亡竞赛恢复此前保存的伤害选项。
- 死亡竞赛倍率200、十武器/升级开放，但原ResetWeapons清空非手枪弹药，开局选无限弹手枪，通过补给取得其他弹药。原升级表没有InfinateAmmo项，本批没有把全武器错误设为无限弹。
- 原RandomPickup逆序枚举武器，满弹仍有权重，回血权重依赖已有非手枪武器权重。因此仅手枪时受伤也不能靠该补给回血；此处保留原函数行为。固定地图补给拾取后隐藏，死亡竞赛10秒、其他30秒并保留原倒计时/再初始化两次回调；速度改变时按原FPS换算。敌人掉落触发仍待完整核对。
- 两款游戏均有暂停/继续/返回准备。僵尸暂停冻结世界tick、计时与输入；羽毛球沿用原暂停允许的回调。命令由服务器校验席位、局号、递增序号，刷新/观战/完整快照恢复保持状态；暂停旧动作不延后释放。
- 全屏保持画布按视口最大比例显示。僵尸用小型暂停/继续/返回按钮；羽毛球现有画面MENU/P区域可点击，机器人点击工具区不会击球。
- 僵尸个人额外按键按浏览器保存，可清除/检测重复；额外按键可覆盖非必需快捷键。WASD、方向键、空格、回车、数字选枪与P始终保留。触屏换枪不受物理K改键影响，取消触屏攻击不会留下缓存攻击。恢复默认游戏选项保留当前地图、模式及人物。

## 原作依据与复现

基准 `games/50737/game.swf`，来源哈希及AS2方法哈希记录于 [选项常量](../../../tests/fixtures/boxhead-options-source.json)。`scripts/import-boxhead-options.py`读取JPEXS导出并提取原SetDifficulty、GetCollection、三模式、速度与死亡上限；这是静态来源依据，不能证明完整游戏时序等价。

`scripts/prepare-boxhead-pickup-reference.py`把原RandomPickup放入隔离AVM1场景，`scripts/trace-boxhead-pickup-reference.cjs`用Ruffle `0.6.0-nightly.2026.8.6`实际执行，`scripts/collect-boxhead-pickup-reference.cjs`采集 [40条原函数结果](../../../tests/fixtures/boxhead-pickup-as2.json)。覆盖空池、仅手枪、满弹、多武器、受伤、权重边界与一次随机消耗；武器由AddWeapon观察，回血由原HP变化观察。Ruffle隔离函数结果不等于独立Adobe Flash整局验证；原全局集合、创建/枚举历史仍须继续。
