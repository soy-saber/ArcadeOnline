# 假墙生命、损毁和原烟雾

原 `CThing_Object_Wall` 的生命/最大生命均为1000，原 `Object.Wall` 有十帧损伤图。地图159面预置墙和玩家放置假墙均恢复原生命值；存活时按原 `floor((1-life/maxLife)*frameAmount)` 选图，保留原浮点表达式及原素材中的重复帧。致命受伤清除后续受伤标志，退出前不再更新损伤图，故保留上一幅非致命画面。透明度在致命回调立即变80%，随后60/40/20/0%；删除进入队列，到下次Dispose才释放移动阻挡。

伤害先按原 `CThing.Affect` 收集，墙回调再处理，防止一发霰弹枪前面的弹丸击碎墙后，后面的弹丸在同次释放中穿墙。原AS2使用for-in；根据 [固定Ruffle AVM1属性迭代](https://github.com/ruffle-rs/ruffle/blob/045db00b393aed22a462d29cb6c25efa26be90a0/core/src/avm1/property_map.rs#L92-L99)、同版本ScriptObject.get_keys和Enumerate，连续push的数组按最近插入项优先处理。混合伤害的非致命尾帧、致命归属与丢弃剩余队列有独立测试。这是固定主实现与原源码的推断，尚未Flash运行时逐帧跟踪；平台仍按武器/投射物/效果/敌人/墙分阶段，并未完成整个AS2集合顺序移植。

损毁生成原烟雾和焦痕，不凭空增加一次爆炸。原 `Effect.SmokeCloud` 外层符号627只有1帧，内部 `_Contents` 符号626实际15帧；旧导入只导出外层首帧。本次静态延长分析副本的外层时间轴，使JPEXS逐帧导出内部原动画并保留滤镜，原游戏SWF不变；PNG/SVG注册位置和逐帧边界/哈希保存于 `src/expanded/boxhead-wall-art.json`。原十段墙图含9幅不同像素图，烟雾15帧全部不同。正式导入脚本也调用本次导入，避免以后重新导入又退回单帧。

烟雾在下一集合回调登记并立即前进1帧，最后一帧保留至随后的清理；待执行出生tick、生命、墙的生命/帧、受伤队列及渐隐/删除tick可完整/增量恢复。烟雾完整资源在等待预览期间预取；运行中的客户端只绘制快照对应帧，浏览器刷新不会推进或重启动画。图像保留静态SVG注册和原PNG尺寸，不宣称与Flash整帧像素等价。

[双浏览器过程](results.json)：正常手枪/UZI杀32只原100HP僵尸，峰值33，实际解锁并放置一面1000HP假墙；自然得到双倍伤害后的手枪实际命中20次，每次52伤害。另一个浏览器观察全部十段损伤图，半血完整恢复保持生命/帧不变；致命受伤后在渐隐期请求完整恢复，保留原消失tick和透明度，不重生墙或烟雾。玩家按住方向朝墙移动，渐隐期间仍被挡住，Dispose后真实通过；原45×49墙和134×134烟雾逐帧绘制通过。截图：[第九段损伤](wall-damage-nine.png)、[原烟雾](wall-native-smoke.png)。
