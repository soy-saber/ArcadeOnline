# Shooter server reconstructions

The native adapters `50737-server` and `97734-server` run simulation in Node, send authoritative snapshots, and lazily draw original extracted art in Canvas. No SWF runtime, creator-stream, client hit reports or client world-state writes are involved. Raw SWFs were preserved.

## Evidence and provenance

These findings use ordinary shell/JPEXS evidence. REA MCP tools and an installed REA CLI were absent; no REA Evidence IDs are claimed. JPEXS 26.4.0 exports are in `artifacts/swf-analysis/50737` and `97734`. Both exported AS2 trees contain obfuscation and some JPEXS invalid-property diagnostics. Readable source and SWF structural masks are used where available; static export is not runtime verification.

- Boxhead `scripts/__Packages/CMain.as:22`: 25 FPS. `Thing/Creature/CThing_Creature_Player.as:147` gives speed 0.16 map cells, :150 gives 200 life, :183 gives gradual regeneration, :242 confirms Coop and an other-player reference. SWF exports contain `World_Init_Player1` and `World_Init_Player2`; two human seats are represented without bots.
- Boxhead `Thing/Weapon/CThing_Weapon_Pistol.as:22` gives rate 8, unlimited ammo, damage 26; UZI source gives rate 4 / ammo 100 / damage 35; Shotgun gives rate 12 / ammo 20 / damage 51; Rocket gives rate 12 / ammo 20 / damage 250; Grenade gives rate 12 / ammo 20 / damage 150. These constants are used by the server.
- Boxhead `DefineSprite_755_TMP2639qh3hat/frame_1/DoAction.as` contains original XSI rotation/animation polygon coordinates and material tables. `import-expanded-boxhead.py` parses object literals without executing AS2, merges `Empty` model deltas against the Player partner, and renders eight directions/eight frames. Original polygon shapes and solid material colors are retained. Bitmap-mapped materials use approximate flat fills. Original barrel, pickup and wall sprites come from DefineSprite 631, 645 and 660.
- Gun Mayhem's `game.swf` is a loader; `games/97734/yy1-1.swf` contains gameplay. Its header is 900 × 600 at 35 FPS. `scripts/frame_10/DoAction.as:236` gives gravity .88, ground friction .93, air friction .88, movement acceleration .7 and jump power 13.5. Lines 269–303 separately attach human `player` and `playerAI` for four slots; only occupied human seats are created.
- Gun Mayhem original hidden platform collision masks are DefineSprites 1838, 1872 and 1875, referenced by map timeline 1940. `import-expanded-gunmayhem.py` segments their opaque connected components and scales original relative layouts into the native arena; `src/expanded/gunmayhem-data.json` records those rectangles. Map labels are native labels, not recovered originals. Player 823, crate 784 and gun 373/434/484/515/609 art is extracted from the same SWF.
- Each runtime asset directory includes `provenance.json` with source SHA-256 and extraction limitations. Original files and exported evidence are not rewritten by asset import scripts.

## Playable scope and reconstruction choices

Boxhead now implements two-to-four-player cooperation, directional aim, five weapons, ammunition and fire-rate limits, kill-based weapon unlocking, combo score, zombies, fireball devils, pickups, wall/object collision, explosive barrel chains, three lives with protected respawns, and a six-wave victory/final defeat. Four human slots/spawns are a requested native extension beyond the two-player SWF; the catalog labels this existing resource reconstruction “僵尸危机3 · 四人服务器联机版”, retaining ID `50737-server`. Native obstacle layouts, exact spawn schedule, zombie balancing, upgrade thresholds and finite round objective are authored choices. The original map selector/complete layouts, full weapon/upgrade catalog, deathmatch and campaign behavior are not faithfully reproduced. Source life/speed/weapon baselines and original polygon art are retained; this is a playable native reconstruction, not a pixel-exact port.

Gun Mayhem implements four-human stock combat, two jumps with input rising edges, platform drop-through, original global physics constants, four gun classes, bullet knockback, damage-scaled knockback, finite ammo, weapon crates, bounced fuse grenades, offstage stock loss, protected respawns and last-player victory. Weapon impulse/timing, stock count, damage accumulation, crate scheduling and spawn selection are native balancing choices. Three original relative collision layouts are available; complete 22-map/campaign/customization/perk/weapon behavior is not ported. The source Chinese invincible modification is not applied to competitive rounds: finite five-stock rounds are used so multiplayer reaches a result. Raw invincible SWF remains available under its original entry.

Attack/alternate counters are monotonic and consumed once; held jump state cannot cause repeated jumps. Malformed input objects are ignored. Simulation uses seeded integer RNG, no DOM, wall clock or randomness outside state. `valid` checks game identity, finite fields, per-game entity fields, array bounds, unique occupied seats and map/gun identities. Optional prediction moves only the local pose; it does not spawn weapons or decide damage, score, deaths or winners.

## Validation

Run `node --test tests/expanded-boxhead.test.cjs tests/expanded-gunmayhem.test.cjs`. Eleven tests cover deterministic simulation, occupied human slots, original-map geometry, duplicate/invalid controls, weapon unlocks, zombie defeat, cooperation round results, double-jump edges, bullet knockback, offstage killer/winner attribution, grenades/crate simulation and rejected invalid snapshots. Asset sheets were visually inspected. Full browser network integration is handled by the shared authority framework; runtime parity with Flash is not asserted.

Rebuild extracted runtime assets with `node scripts/import-expanded-boxhead.cjs` and `node scripts/import-expanded-gunmayhem.cjs` using existing Java/FFDec and Python/Pillow. The wrappers export to analysis directories and preserve source files. FFDec diagnostics are saved to logs, including any script-decompilation limitations. When exports already exist, the `.py` scripts rebuild only the compact asset set.
